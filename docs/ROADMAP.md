# Development roadmap

- [x] Milestone 0: browser viewer starter scaffold (companion folder `namma-space-starter`)
- [x] Milestone 1A: RGB reconstruction pipeline scaffold (COLMAP + Open3D)
- [ ] Milestone 1B: install/verify COLMAP and Open3D on the target Windows laptop
- [ ] Milestone 1C: run on a real iPhone Pro capture and inspect registered images / mesh
- [ ] Milestone 1D: calibrate scale and improve mesh fidelity
- [ ] Milestone 1E: connect generated GLB to viewer; verify free roaming
- [ ] Milestone 2A: accept synchronized RGB + depth exports from a confirmed capture app
- [ ] Milestone 2B: floor-wise reconstruction and measured alignment
- [ ] Milestone 3: AI-assisted semantic suggestions + human-approved POI labelling
- [ ] Milestone 4: spatial index and obstacle-aware navigation
- [ ] Milestone 5: WebXR AR navigation

No milestone is marked complete until it has been run and tested on actual data.
